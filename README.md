# haskell-playground

Functional programming practice in Haskell.

- `PgmUsr/`: small reporting exercise, parses `ps -aux` style text input and prints a sorted report of the fields that matter (PID, path, program name, UUID).
- `nix/`: flake-based Haskell dev environment plus small expression exercises.
- `samplefiles/`: scratch inputs and compiled experiments.

Learning scratchpad, not production code.
